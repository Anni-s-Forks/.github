### 📌 About This Hub

Welcome to **Anni's Forks Hub**! This organization serves as a dedicated, organized environment for maintaining active open-source forks, experimentation with native Android frameworks, community tools, and learning references.

By maintaining forks in this dedicated organization, the main profile [**@Ankesh-Kumawat**](https://github.com/Ankesh-Kumawat) remains 100% focused on original engineering projects.

### 📂 Curated Collections

#### 🎵 1. Android & Cross-Platform Music Streaming Players
* **BitChord** — Modern YouTube Music client with clean aesthetics.
* **PixelPlayer** — Privacy-first Android music player with Material 3 Expressive.
* **LastWave-Native** — High-resolution lossless music player with synced lyrics.
* **vivi-music**, **SuvMusic**, **SimpMusic** — Open-source music exploration clients.

#### 🎬 2. Media, Video Editing & AI Agents
* **auto-cut-agent** — AI video editing agent for Adobe Premiere Pro (silence removal, dedup).
* **omniclip** — Open-source video editing web application.
* **SimpleVideoEditor** — Android video editor using Mp4Composer.
* **openreply** & **open-autodm** — Open-source self-hosted Instagram & DM automation.

#### 📱 3. Anime Discovery & Manga Readers
* **AniSync** — Native Android client for AniList built with Jetpack Compose & Material 3.
* **Aniraku-App** — Native Android anime discovery, playback, and library.
* **Usagi** — Lightweight manga reader for Android.

#### 🛠️ 4. Reverse Engineering & Developer Tools
* **rea** — Reverse engineer app behavior with autonomous agents.
* **apk-reverse** — Android APK reverse engineering & static analysis toolkit.
* **Android-Dex** — Universal Samsung DeX alternative for Android devices.
* **private-agent** — Android automation agent via Accessibility Services & LLMs.
* **mapbox-maps-flutter** — Flutter Mapbox integration.
* **youtube_explode_dart** — Dart YouTube extraction & streaming API.
* **nav_bar_app** — iOS 26 Liquid Glass tab bar Flutter demonstration.
